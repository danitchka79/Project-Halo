MICI Float Comparison Calculator

Every option gets the same planter (substrate) volume and the same total buoyant volume (floats + buoyancy chambers). The calculator works out the geometry each option then needs, and compares planting area, gap between planters, plastic and floating behaviour. Concept-level estimate only: not a substitute for a stability and structural check.

Definitions

a: planter inner width (across flats for polygons; across the floats for two parallel floats)
b: outer width of the module (across flats)
w: float width (ring width; width of each parallel float; top width of an L-shaped float)
sa, sb: side length of the planter / of the outer edge
L: length of the two parallel floats (and of the planter between them)
p, Dp: width and depth of each attached non-buoyant planter
Ds: substrate (planter) depth, from the deck/substrate surface down to the planter floor
d: float depth, the full height of a float from deck to bottom
hf: foot height of an L-shaped float, the part below the planter floor: hf = d − Ds
e: how far the foot of an L-shaped float reaches in under the planter
hb: height of a buoyant base under the planter
Vp: planter volume (substrate, plus water pockets if soil cells are used)
Vb: total buoyant (air) volume: floats + pipes
Vch: buoyancy pipe volume inside the planter; Vrem: the rest, in the floats
Gap: clear distance between planters of neighbouring modules (substrate edge to substrate edge)
Freeboard f: height of the deck (= substrate surface) above the water
Draft: depth from the waterline to the lowest point of the module
Reserve buoyancy: extra load the module can carry before the deck goes under
Floating forest OK: gap ≤ the floating-forest limit, so canopies and roots can join up
"mangroves–path–mangroves" OK: a float path runs between planters. Always OK when the floating forest is OK, with attached non-buoyant planters, and for hexagons and octagons; otherwise when the path is at least the minimum width
Floating forest: lower density: attached non-buoyant planters give a sparser forest (trees in separate pots)
"path–mangroves–path": floats on the outside of the mangroves (two parallel floats without attached planters)

Equations

x = width across flats (m). Shape constants: area A = k·x², perimeter P = c·x.

Side length: s = x · tan(π/n)  (n = 4, 6, 8) → square s = x, hexagon s = x/√3 ≈ 0.577x, octagon s = (√2 − 1)x ≈ 0.414x
Square: k = 1, c = 4  ·  Hexagon: k = √3/2 ≈ 0.866, c = 2√3 ≈ 3.464  ·  Octagon: k = 2(√2 − 1) ≈ 0.828, c = 8(√2 − 1) ≈ 3.314

1. Buoyancy chambers (pipes)

Vertical pipes: Vv = nv · (π Dv² / 4) · Lv
Horizontal pipes (wall to wall): Vh = (π Dh² / 4) · Σ Li,   Li = chord of the planter at the pipe's position
Total chamber volume: Vch = Vv + Vh

2. Planter (same substrate volume Vp for all options)

Planter inner area: Ain = (Vp + Vch,in) / Ds
Planter inner width: a = √(Ain / k)
Planting (surface) area: Aplant = Ain − nv · π Dv² / 4
With soil cells (fraction fc of the planter): substrate = (1 − fc) · Vp;   cell plastic = p · fc · Vp;   water pockets = (1 − p) · fc · Vp  (p = plastic fraction, default 5%)

With soil cells, Vp is the planter volume: the planter stays the same size, and the cells replace part of the substrate with water. Water pockets below the waterline are neutral (they weigh what they displace); above it they drain. So they add no load, and the module carries less substrate weight. Vch,in = chamber volume inside the substrate layer (vertical pipes up to depth Ds, all horizontal pipes). Chambers take space that would otherwise be substrate, so the planter grows to keep Vp constant. Because Vh depends on a, a is found by iteration.

3. Remaining buoyancy (same total Vb for all options)

Vrem = Vb − Vch
Perimeter ring (depth d): k(b² − a²) · d = Vrem  ⇒  b = √(a² + Vrem / (k d)),   ring width w = (b − a) / 2
Two parallel floats (floats of length L along two opposite sides; planter a × L with a·L = Ain, L = a unless set): 2 · w · L · d = Vrem  ⇒  w = Vrem / (2 L d),   b = a + 2w,   footprint = L · b
Two parallel floats + attached non-buoyant planters (width p, depth Dp, one outside each float): b = a + 2w + 2p;   each a p × p pot centred on the float side, so neighbouring pots along the run have gaps; extra substrate 2 p² Dp (buoyed where submerged);   planting area = Ain + 2 p²;   gap = w (attached planters of neighbouring modules touch)
Two parallel L-shaped floats (top width w beside the planter, float depth d, foot of height hf = d − Ds reaching e under it): 2 L [w Ds + (w + e) hf] = Vrem ⇒ e = (Vrem/(2L) − w Ds)/hf − w;   gap = 2w
Stepped (L) floats (top width w beside the planter, float depth d, so the foot below the planter floor has height hf = d − Ds): b = a + 2w;   Vtop = k(b² − a²)·Ds;   Vfoot = k(b² − ai²)·hf;   Vtop + Vfoot = Vrem ⇒ ai = √(b² − (Vrem − Vtop)/(k hf)),   foot extension e = (a − ai)/2; gap = 2w
Buoyant base under the planter (hexafloat-type): hb = Vrem / Ain,   b = a + 2t
Footprint: Aout = k b²  ·  Planting ratio = Aplant / Aout
Minimum gap between neighbouring planters: ring → 2w (two rings side by side); two parallel floats → 2w across the floats, ~0 along them; base → 2t (walls only)

Float sizing. "Same total buoyant volume" fixes Vb for every option. "Size floats to a target freeboard" instead solves Vrem (by bisection) so each option sits at the target freeboard: a lighter module (e.g. with soil cells) then gets narrower floats.

Submerged-substrate mode. Give the share of the substrate depth that should sit below water, q: target freeboard = (1 − q) · Ds (deck level = substrate surface). Floats are then sized to that freeboard.

Stability and natural periods

Depths z measured down from the deck; keel = lowest point (zmax). KG = zmax − zG, KB = zmax − zB
zG = Σ mi zi / M  (substrate at Ds/2, floats at their mid-depth, deck and live load at 0, tree at −ztree)
zB = Σ Vi zi / Σ Vi over the submerged parts (floats, buoyed substrate, pipes)
BM = Iwp / Vdisp,   GM = KB + BM − KG = (zG − zB) + BM
Polygon second moment of area: I = A (6R² − s²)/24 (R = circumradius, s = side); rectangles: I = L w³/12 + L w yc²
Heave: Th = 2π √( M (1 + Ca,h) / (ρw g Awp) )
Roll / pitch: Tr = 2π √( IG (1 + Ca,r) / (M g GM) ),   IG = Σ mi (ki² + (zi − zG)²)

Small-angle hydrostatics with the porous substrate counted as buoyant volume (it moves with the module). Added-mass coefficients are rough inputs; use a diffraction model (e.g. ANSYS Aqwa) or flume tests for design values. Periods ignore mooring stiffness and connections between modules.

4. Plastic (wall area × thickness t × density ρpl)

Ring: S = (c b + c a) · d + 2 (Aout − Ain)
Two parallel floats: S = 2 · 2 (w L + w d + L d)
Stepped floats: S = c b (Ds + hf) + c a Ds + c ai hf + k(b² − a²) + k(a² − ai²) + k(b² − ai²)
Base: S = 2 Ain + c a · hb
Pipes: S = Σ (π D Li + π D² / 2)  (Li = wall-to-wall chord for horizontal pipes)
Planter shell (optional): S = c a · Ds + Ain
mpl = S · t · ρpl

Assumes one continuous ring float. Real perimeter floats are segmented, which adds end walls, so ring plastic is a lower bound.

5. Flotation (vertical equilibrium)

ρw · Vdisp(f) = M = msub + mtree + mpl + mdeck + mlive
msub = ρsat · Vp,   mdeck = qdeck · Apath,   mlive = (qlive / g) · Apath
Vdisp(f) = Σ prisms Ai · max(0, zbot,i − max(ztop,i, f)) + Vp · max(0, Ds − f)/Ds + Σ Li · Aseg(f)
Submerged pipe segment (radius r, centre depth zc, h = zc + r − f): Aseg = r² cos⁻¹((r − h)/r) − (r − h)√(2rh − h²)

f = depth of the waterline below the deck / substrate surface (freeboard), solved by bisection. Depths are measured downward from the deck. Ring floats span 0…d, vertical pipes 0…Lv, substrate 0…Ds, horizontal pipes lie on the planter floor, and the buoyant base spans Ds…Ds+hb. The planter is treated as porous: submerged substrate is buoyed by the water around it. Reserve buoyancy = ρwVdisp(0)/M − 1.

Gap = clear distance between the two planters (substrate edge to substrate edge). Click a picture to show or hide the mangroves (a tree per planter; trees in small attached planters are full size, with roots growing out of the planter).
